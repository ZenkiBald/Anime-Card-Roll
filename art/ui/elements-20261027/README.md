# Element icon set (2026-10-27)

Six individual transparent illustrations generated with the built-in ImageGen tool:
Flame, Frost, Storm, Void, Cosmic and Light. The full-size originals are here; `upload/`
contains the 384 px RGBA copies uploaded to Roblox. No enclosing diamonds or text tags.

`generation-plan.json` contains the exact prompt set. `manifest.json` records the prompts,
source paths, dimensions, hashes and asset ids; `asset-ids.json` preserves the upload receipt.
The central registry is `src/shared/Elements.luau` (`Elements.Visuals`); `UI/ElementUi.Badge`
renders the actual images in collection, reveal, inspector, formation and battle card badges.
